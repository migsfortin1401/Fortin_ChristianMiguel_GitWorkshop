**Project Title:** Personal Portfolio Website

## Brief Description

This project is a simple personal portfolio website that presents basic information about me, my skills, and my projects. The website was created using HTML and was developed through different versions using Git.

## Reflection

In my own words, `git add` and `git commit` have different purposes. The `git add` command prepares the changes and puts the selected files into the staging area. On the other hand, `git commit` records those staged changes permanently in the Git repository with a message. In simple terms, `git add` prepares the changes, while `git commit` saves them as a version in the project's history.
